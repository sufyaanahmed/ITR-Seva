# Website audit, 5 September 2026

## Fixes

- Reject impossible calendar dates in the shared browser/backend form validation, including non-leap-year February 29 and February 31.
- Let applicants retry failed list/detail requests and return to My applications from a failed detail load. Reset stale detail state when the application ID changes.
- Let administrators retry an initial access-check failure.
- Initialize the admin action selector to a valid option for the application's current status, avoiding a displayed/submitted value mismatch.
- Reset the file input after selection so removing and selecting the same file works. Ignore stale asynchronous image validation after replacement or removal.
- Apply the backend's 10 MB upload ceiling to routes without a stricter document limit, reject empty files, and decode all selected JPEGs. The interface distinguishes the platform upload limit from document specifications.
- Download private documents using the signed attachment URL without relying on an asynchronous popup.
- Start a fresh application from My applications without reusing previous answers, uploaded-file references, or cloud identifiers. Ordinary finder Back navigation still preserves selections.
- Match the mobile navigation label to the enabled application platform.
- Give the not-found page a primary heading and improve the Help call-to-action's text contrast.

## Scope and remaining configuration

This is a functional and regression audit, not an exhaustive penetration test or a guarantee that every browser/device path is defect-free. API lifecycle coverage is broader than manual browser coverage.

Payments remain sandbox simulations; no live gateway was enabled. Hosted notification tests verify queueing, not external delivery. Switching to Supabase's built-in sender remains pending the previously requested approval of the SMTP reset dialog and its stated template/rate-limit effects.

The local build reports an approximately 517 KB uncompressed main JavaScript chunk (151 KB gzip). This is a performance follow-up rather than a build failure; the hosted applicant build is smaller under its environment configuration.
